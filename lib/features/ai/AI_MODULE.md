## 目标

在已有专注数据之上提供「增值解读层」——用户主动触发的自然语言复盘。
AI 不是新交互入口，不改变计时主流程；AI 任一环节失效，计时与统计零影响。

## 功能（唯一）

- **AI 周报解读（V0.5）**：本地洞察引擎产出结构化洞察 JSON →
  用户在统计页主动点「AI 解读」→ 云端 LLM（首选 DeepSeek，经
  `LlmProvider` 抽象可换 Kimi/通义）生成 ≤3 段复盘 + 1 条建议。
  无网/未配置 Key 时退化为现有纯结构化周报。

> 2026-08-27 所有者决策：TTS 语音播报与语音速记曾列入本模块
> （V0.5 播报 / V0.6 速记），已砍掉——专注单一云端路线、降低硬件
> 联调风险；端侧 ASR/TTS 调研结论见 docs/05 留档备查。

## 依赖与接口

- **数据来源（只读，不回写）**：stats 域 `weekly_report.dart` /
  `focus_heatmap.dart` / `focus_interruption.dart` / `elastic_streak.dart`，
  以及 `core/timer/session_record.dart`。
- **`InsightEngine`（core/insight，纯 Dart）**：本地规则 → 结构化洞察 JSON；
  数字与判定全部本地完成，LLM 只负责润色。
- **`LlmProvider`（core/ai，抽象接口）**：`generateInsight(prompt)` /
  `ping()`；统一超时与错误降级，任何失败静默退化为结构化周报。
- **隐私**：只上传白名单字段（周时长/次数/时段分布/弹性连续天数/
  Top 中断来源的匿名类别），剥离设备标识；同意记录落库；默认离线可用。

## 版本映射

- **V0.5**：AI 周报解读（默认关闭，需开启并单独同意）；
- **远期实验项（不承诺）**：端侧 1B 级小模型打标/分类；
  **端侧 LLM 对话在骁龙 680 上不可行，不做**；语音类功能已砍（ADR-0006）。

## 安静原则红线（违反即打回）

1. AI 永不在计时进行中发声/弹窗/主动推送建议；
2. AI 输出只在用户主动查看处呈现；
3. 设置页提供一键全局关闭 AI 的总开关，关闭后隐藏全部入口、
   停止一切云端请求；
4. AI 功能全部默认关闭，需用户主动开启并单独同意数据使用说明。

## 接入点

- UI：统计页周报卡片「AI 解读」按钮；
  设置页新增「AI 功能」区（总开关 / API Key / 隐私说明）；
- 状态：新增 `AiController`（Riverpod），管理开关、同意、降级状态；
  总开关关闭时 UI 入口整体隐藏且服务不初始化（ADR-0003 裁剪粒度）。
