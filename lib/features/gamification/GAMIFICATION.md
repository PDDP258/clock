# 游戏化（V0.4 预留）

## 目标

用轻量游戏化机制强化「坚持专注」的正反馈，服务自律主线，不做重度养成。

## 候选机制

- **连续打卡（streak）**：每日完成 ≥1 轮完整专注即记一天，连续天数展示；
  断签清零。数据可直接从 drift `focus_session` 聚合得出。
- **目标系统**：drift `goal` 表已预留（dailyFocus / weeklyFocus / streak 三类），
  设置页加「目标」入口，达成给徽章。
- **等级 / 经验**：专注分钟数 = 经验值，线性升级，仅作展示，无付费点。
- **皮肤奖励**：主题系统已预留 `AppSkin`（`lib/app/theme.dart` 的
  ThemeExtension），新皮肤作为升级/活动奖励解锁。

## 设计约束

- 一切游戏化元素可关闭（设置页总开关），不影响计时核心功能；
- 不引入联网排行榜（M500 为离线优先设备）；
- 数据全部本地，复用 drift，不新增第三方存储。

## 接入点

- 数据来源：`FocusSessions` 表聚合（轮数、时长、连续天数）；
- 状态：新增 `GamificationController`（Riverpod）；
- UI：统计页加「成就」区块；`AppSkin` 扩展新主题。
