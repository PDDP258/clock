## 2026-10-07 晚 · 暂停改色修复 + 进度条闪边回退（看板 #63）

PD 真机反馈两条：① 计时中暂停时颜色「计时蓝 → 休息红 → 蓝」闪一下；② 底部进度条的回零闪边不该动，要求回退。

### 根因（两层，都不是「选错颜色」）
先查证过：`accentColor` 在三套皮肤里都 == `focusRingColor`，休息红只在 shortBreak/longBreak 分支出现——所以「变红」不可能来自 paused 分支。真正两层：
1. **语义层**：`paused` 被当成独立阶段取色（`paused => accentColor`）。而引擎里早就有 `TimerEngine.phaseBeforePause`（暂停前的阶段）却从未被 UI 消费。
2. **动画层**（这才是「红」的来源）：时钟交叉淡化起点 `_prevColor` **只在颜色变化时写、从不清理**。上次转场留下的旧色（如很久前某休息段的红色）长期滞留；下次转场若颜色恰好没变（暂停/继续正是如此），就拿陈旧色当淡化起点。

### 改动
- `focus_controller.dart`：`FocusViewState` 加 `phaseBeforePause` 字段 + 派生 `colorPhase`（paused 取 phaseBeforePause），`_emit` 透传，copyWith 支持。
- `focus_page.dart`：横屏 3 处 + 竖屏 3 处颜色映射全部改走 `state.colorPhase`；正计时 paused 并入 running 色。进度环修掉「paused 硬编码专注色」历史 bug（休息阶段暂停会闪成专注色）。
- `_GlanceClockState._prevColor` → `_swapFromColor`，**非转场时置 null 作废**，且 `from == widget.color` 时不播淡化。
- `_PhasePulse` / `RoundTransition` 的 phaseKey 改用 `colorPhase` → 暂停不再触发整屏脉冲与 1200ms 换段编排。
- 进度条闪边**完全回退**（`_flash` / `_lastProgress` / 闪边图层三处全删）。
- 新增 `test/phase_color_test.dart`（8 例，含「暂停↔继续 colorPhase 相同」这条关键性质 + 引擎侧 phaseBeforePause 联动）。

### 教训（已入 AGENT.md §6-69）
- **引擎记忆的语义信息要透出到 view state**，否则 UI 会自己瞎猜。`phaseBeforePause` 早就在引擎里，UI 却另起一套 `paused => accentColor`。
- **为「下一次动画」缓存起点/前一状态的字段，必须在动画结束时作废**——起点色是会过期的状态。
- 一处语义变更要同时问三件事：取色映射、动画起点缓存、状态变化触发键。
- 教训：查「颜色从哪来」先穷举色的来源（`grep` 皮肤色定义），发现 `accentColor == focusRingColor` 就该立刻排除该分支，而不是先改了再说。**先证伪再动手**。
- 写测试时 `PomodoroConfig` 参数名是 `focusDuration/shortBreakDuration/longBreakDuration`（不是 `focusMinutes`）；`build` helper 放 main 外面才能被两个 group 用。
