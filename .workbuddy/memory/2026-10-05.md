## 2026-10-05 晚 · 图库管理收口 + 选图「未选择」根因修复（看板 #61）

PD 真机反馈：加图调的是文件管理器且选完显示「未选择」；要求去掉扫描投放目录、清空我添加的图片两个功能，加图让用户二选一（相册/文件管理器）。

### 根因（选图失败）
`ACTION_OPEN_DOCUMENT` 外包了 `Intent.createChooser` → chooser 转发让部分文件管理器返回的 URI 带不上读权限 → 原生探测 SecurityException 被吞 → Dart 收空列表显示「没有选到图片」。官方文档明确 OPEN_DOCUMENT 不应配 chooser。**AudioToolsPlugin 选音频同款问题一并修了。**

### 改动
- `BackgroundImportPlugin.kt`：去 chooser 直接拉起；`pickImages` 加 `source`（gallery=ACTION_PICK+MediaStore / files=OPEN_DOCUMENT）；探测 fd 失败退流（openInputStream，EXIF 流构造 API 24 守卫）；探测失败条目 width=0 回报（区分「没选」与「读不出来」）；删 `probeImages`/`probeFile` 与 process 的文件分支。
- 通道 `background_import_channel.dart`：`pick({required source})`，`BgPickSource` 枚举，删 `probe`、模型去 `isUri`。
- `bg_import.dart`：`fromGallery()`/`fromFileManager()`；删 fromInbox/clearUserLibrary/bgInboxPathProvider/bgManifestPathProvider。
- `background_store.dart`：删 inboxDir/scanInbox/clear；`bg_image.dart` 删 kBgInboxDirName。
- `gallery_manage_page.dart`：删页尾两个 ListTile；加图弹底部二选一（相册推荐）；禁用数>0 顶部提示行。
- 测试重写对齐；新增 remove 用例。
- frontend_server 编译 main.dart 与 test 文件均 RC=0；**flutter test + build apk 仍待 PD**。
