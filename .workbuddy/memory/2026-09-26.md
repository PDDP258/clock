## AI 调性轮（看板 #53，解「太枯燥」）

触发：用户「AI 功能太枯燥了，继续按上一次的标准修改」→ 按 docs/08 第 2 批推进，主轴定为「调性」。

### 根因（三层，最根本的一层不在提示词里）
1. **没料可说**：洞察只有 8 个孤立数字（其中 3 个是总量），能说的「关系」根本不存在于数据里。而暂停时间戳 / 单段长度 / 会话日期**一直在库里**，只是从没被聚合。
2. **表达被中性化**：角色写「克制、务实」+ 硬约束只有「禁」没有「要」+ 温度 0.3 → 对模型而言最安全的写法就是**照事实块逐行复述**。
3. **结构单调**：三段平铺 + 一条建议，没有层次。

关键边界判断：「表现不错」的毛病**不在于它是正面的话，而在于把数字换成了形容词**。反鸡汤该禁的是「没有信息量」，不是「有性格」。08-A5 那版把两者一起禁了，代价就是枯燥。

### 落地
- **B3 洞察扩容**（`insight.dart` / `insight_engine.dart`）：+8 字段——中断时段分布（按次数归桶，未闭合暂停无时长）、中断占比、单次均值、最长连续段 + 所在时段、最专注的一天、有记录天数。白名单 11→19 字段，07 §4.1 表同步，并删掉该表里本就**不存在**的 `top_interruption_categories`。
- **E1 提示词调性**（`ai_prompt.dart`）：硬约束拆【数字纪律】【禁止空洞】【要求具体】三组；新增「至少给出一处数字之间的关系」「第一句必须是『发现』不是『概述』」「可以说人话、可以用比喻」；角色由「克制、务实的助手」改为「擅长看出关系、说人话的复盘搭档」；事实块 8→13 行。
- **E2 题目扩充**（`ai_ask.dart`）：周报 3→5 题（+「什么时候最容易被打断」「时间花得值吗」）、当日 3→4 题（+「这天最值得说的是什么」——强制取舍的开放题）。
- **E3 缓存版本**：`kPromptVersion='v2'` + `cacheFingerprintOf()`，`ai_controller` / `daily_comment` 两处接入 → 改了提示词，旧解读会给一行「数据已更新，点重新解读」，**仍不自动重发**。
- **温度**（`deepseek_provider.dart`）：0.3 → 0.6。数字确定性靠硬约束 + 本地算数，不靠温度。

## AI 记忆日志（看板 #54，跨程序记忆）

触发：用户「增加自动保存日志功能……做日志是为了方便我将本程序的 ai 和其他程序联动，通过日志修改来达到传递记忆功能，所以日志格式务必严谨」。

需求拆解：一天一条 / 当日多次写覆盖当日 / 一个文件存多条 / 预留读近七日 / 格式严谨 / 目的是跨程序互操作。

### 核心设计决策
1. **JSONL（一行一个 JSON）而不是大数组**：追加与局部修改成本最低（改一天只重写一行）；数组结构写入中断即全文件报废。人可读、脚本可写、diff 友好。
2. **文件位置沿用备份通路**：应用专属外存（免权限、文件管理器可见），与 `mikufocus_backup.json` 同目录。
3. **字段级所有权（这套格式的关键）**：`date` 是唯一键；应用重写当日条目时**只覆盖自己拥有的键**（schema/date/rev/updated_at/prompt_version/facts/note/insight），其余键（含外部约定键 `memory`）**原样保留**。→ 同时满足「当日覆盖」与「外部记忆永不被冲」两个看似冲突的要求。
4. **注入不含当日**（`[今天-7, 今天-1]`）：当日数字已在事实块里，两边都注入就是「同一份数据两个口径」（§6-51(a) 同族错误）。读取 API 提供 `includeToday` 两种口径。
5. **`insight` 不注入**：周报全文 7 天会挤爆预算；「写进文件」与「注入给模型」是两件事。注入 = facts + note + memory，单条截断 60 字、整块上限 900 字（超出丢最早的，保最近）。
6. **容错偏向不丢别人的数据**：`date` 必须合法；schema/rev/updated_at 缺失**不判非法**；坏行进 `invalidLines` 并**原样保留在文件末尾**；容忍 BOM/CRLF/`"210"` 这类写法。
7. **未开启 AI 零副作用**：不建文件、不读不写；一切异常静默（记忆是增强项）。

### 顺带修掉的真问题
`dailyFactsBlock` 把 `- 起止：从 09:12 到 18:40` 写进了提示词，而 docs/07 §4.3 与设置页数据使用说明都承诺「逐次会话起止明细永远不上传」「不发送具体时间点」，设置页另一处还写「起止时间仅存本机数据库」——**三处互相矛盾，且模型看得见的东西就是发出去了的东西**。已移除钟点，数字收敛到新增的 `dailyFactsJson` 单一来源（事实块/上传快照/记忆日志三处共用），并有单测断言不含 `HH:mm`。若不修，新加的 7 天记忆会把这条违背放大 7 倍。

### 落地清单
- `lib/core/ai/memory_log.dart`（新）：模型 + JSONL 编解码 + 字段级 upsert + 近 N 日窗口 + 注入块渲染（纯 Dart）。
- `lib/platform/files/memory_log_store.dart`（新）：唯一读写点，原子写（tmp+rename，退化先删后改名）。
- `lib/features/ai/application/ai_memory.dart`（新）：store/provider + `AiMemoryLogService`（`saveToday` / `recentEntries` / `readInjectionBlock` / `snapshot` / `clear`）。
- `lib/app/app.dart`：结算监听里加 `saveToday()` 自动落盘。
- `ai_prompt.dart`：硬约束 +第 10 条「记忆不得混算」、`composeUserMessage`（记忆夹在事实块与任务之间）、`dailyFactsJson` 单一来源、`kPromptVersion` → v3。
- 三个控制器：请求前读注入块、成功后 `saveToday(note/insight)`、上传快照加 `memory_block`。
- 设置页：AI 区新增「跨程序记忆日志」（路径/条数/近 7 日预览/清空）+ 删除 AI 数据联动清空 + 同意文案升 v2（披露记忆会随请求外发，含外部写入内容）。
- `docs/09-AI记忆日志规范.md`（新）：给外部程序对接的严格规范（字段表/所有权/容错/注入规则/Python 示例/隐私边界/版本兼容/验收要点）。

### 验证
`flutter test` **294 全绿**（基线 257，+37）；`flutter analyze` 0 error / 0 warning（仅 2 条既有 info）。

### 坑
- **同一文件的多处 Edit 不能在一条消息里并行发**：并发写导致后写覆盖前写，3 处编辑静默丢失（表现为「编辑成功但文件没变」）。同文件的多次修改必须串行。
- `'-$_shortDate(e.date)'` 这类**方法未加花括号**的插值：Dart 只插 `$_shortDate`（闭包 toString），后面的 `(e.date)` 成了字面量——渲染出来是一串 Closure 描述而不是日期，且断言失败信息里很难看出根因。
- 测试里 `late Directory memoryDir;` 必须声明在引用它的 `container()` **之前**（late 局部变量不能先引用后声明）。
- 单测里要用 `aiMemoryLogStoreProvider.overrideWithValue(AiMemoryLogStore(directory: () async => tempDir))` 注入临时目录——否则会走 path_provider 抛 MissingPluginException（虽被静默吞掉，但测不到真实写入）。

### 构建期非致命报错（可忽略，勿误判为失败）
```
llvm-objcopy.exe: error: '...\native_symbol_tables\release\extractReleaseNativeSymbolTables\out\
armeabi-v7a\libflutter.so.sym': Permission denied
```
这是 Gradle 的 `extractReleaseNativeSymbolTables` 任务（为崩溃符号化提取 `.so` 符号表）在 armeabi-v7a 上撞到文件占用/杀软锁定所致。**该任务产物不进入 APK**，`assembleRelease` 依旧打出完整三 ABI 包。若想消掉它，删掉 `build/app/intermediates/native_symbol_tables/` 后重建即可。
